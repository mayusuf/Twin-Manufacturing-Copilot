# Raw Data

This directory contains the AI4I 2020 Predictive Maintenance dataset from the UCI Machine Learning Repository.

- Source page: https://archive.ics.uci.edu/dataset/601/ai4i%2B2020%2Bpredictive%2Bmaint
- DOI: https://doi.org/10.24432/C5HS5C
- License: Creative Commons Attribution 4.0 International
- Local CSV: `ai4i2020.csv`

Keep the raw CSV unchanged. Later preprocessing steps should write cleaned or transformed data to a separate directory.
